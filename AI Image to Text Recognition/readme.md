
#  DecodeLabs AI Project 4 — AI Text Recognition
An AI-powered application that extracts text from images using Optical Character Recognition (OCR).

## Features
- Upload images (JPG, PNG, BMP)
- Recognize text using EasyOCR
- Display extracted text
- Download recognized text as a `.txt` file

## Technologies
- Python
- EasyOCR
- OpenCV
- Streamlit

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:

```bash
streamlit run app.py
```

Upload an image, click **Recognize Text**, and view or download the extracted text.
